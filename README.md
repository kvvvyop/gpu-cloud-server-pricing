## GPU 云服务器价格由什么决定？

价格由四块构成：GPU 卡型与数量、CPU 内存配比、存储和带宽、计费方式。GPU 卡是绝对大头，其余三项决定总价会在标价基础上多出多少。

**GPU 型号与显存**。同一代架构里，显存越大越贵，而且是跳档式的贵。以公开报价为例，A100 的 40G 版本和 80G 版本每小时分别是 2.75 元和 8.00 元，显存翻倍，价格接近三倍。贵出来的部分是 HBM 显存和 NVLink 互连的成本——大模型训练时模型参数必须完整装进显存，装不下就得换卡，没有折中方案。

**CPU、内存与存储**。GPU 租用平台通常给每张卡配 8 核 16G 左右的 CPU 内存，够跑数据预处理。存储另算：本地 NVMe 读写快，适合放热数据；数据集和模型检查点要挂持久化存储或并行文件存储，按容量计费。

**网络带宽**。多卡训练靠高速网络同步梯度，InfiniBand 或高速以太网的配置直接影响价格。单机单卡用户感知不强，多机多卡时这条会实打实写进账单。

**计费方式**。按量、包月、抢占式三种模式的价格能差出一大截，后面单独说。

## 按量、包月还是抢占式？

短期或不确定用多久，选按量；每天稳定用 8 小时以上、连续跑几周，包月通常更省；任务能容忍中断，看抢占式。

算笔账。以每小时 0.77 元的入门卡为例，24 小时连轴转一个月（720 小时）是 554 元；每天只用 3 小时，一个月约 69 元。同样的卡，用法不同，月支出差 8 倍。所以"哪家便宜"这个问题，得先回答"你怎么用"。

中端卡同理：每小时 1.65 元的 4090，每天用 4 小时，月支出约 198 元；跑满一个月则要 1188 元，这时候包月的价格优势才显现出来。

包月的单价通常低于按量累计，但各家折扣不同，而且包月往往绑定具体规格，中途升级不灵活。建议先用按量跑一两周，摸清真实使用时长，再决定要不要转包月。

抢占式适合能频繁保存检查点的任务——价格最低，代价是资源紧张时实例可能被回收。训练脚本要支持断点续训，否则被中断一次就白跑。

## 真实成本里容易漏掉的三笔钱

存储、带宽和闲置时间，是账单上最常见的三个"意外"。

**存储**。GPU 实例自带的盘通常只够放系统和代码，数据集和模型文件要挂云盘或并行文件存储，按容量计费。几百 GB 的训练集存一个月，费用不算高，但会实打实出现在账单上，别默认存储免费。

**带宽**。从云端下载模型权重、上传数据集，都走公网流量。包月带宽和按流量计费，长期看差别不小。

**闲置时间**。按量实例只要开机就在计费。写代码、调数据格式这类不需要 GPU 的活，可以先开纯 CPU 模式——公开报价里，2 核 2G 的 CPU 云主机每小时 0.18 元，不到最便宜 GPU 卡的四分之一。把 GPU 留给真正跑任务的时段，一个月能省出不少。
